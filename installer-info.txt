Telemost Right Shift Mic — экспериментальная неофициальная утилита.

Правый Shift переключает микрофон из других окон во время звонка Телемоста.
Обработчик клавиши выключается после звонка. Наблюдатель остаётся в фоне.
Python устанавливать не нужно. Подключение к интернету не требуется.

Проверено: русское настольное приложение Телемост 3.1.3, масштаб Windows 100%.
Кнопка нажимается по координатам: перед разговором проверьте результат
в пустом звонке. Другие версии и интерфейсы не гарантируются.

Установка выполняется только для текущего пользователя, без прав администратора.
Удаление: Параметры Windows → Приложения → Telemost Right Shift Mic.
