# Telemost Right Shift Mic

**[Скачать установщик для Windows x64](https://github.com/willow-wq/telemost-hotkey/releases/latest/download/TelemostHotkey-Setup-0.1.0.exe)** — Python устанавливать не нужно.

[Все релизы](https://github.com/willow-wq/telemost-hotkey/releases)


Экспериментальная утилита для Windows: **правый Shift включает и выключает
микрофон в приложении Яндекс Телемост**, в том числе из другого окна.
Это неофициальный проект, не связанный с Яндексом.

## Как работает

- Фоновый наблюдатель отслеживает запуск `YandexTelemost.exe`.
- Обработчик клавиши включается только при наличии одного окна «Звонок».
- После завершения звонка клавиша снова работает как обычный Shift.
- При полном выходе из Телемоста обработчик завершается. Наблюдатель остаётся,
  чтобы автоматически обнаружить следующий запуск приложения.
- Обнаружение запуска и завершения занимает примерно 1–2 секунды.

Во время звонка одиночный правый Shift занят переключением микрофона.
Для обычного набора заглавных букв используйте левый Shift.

## Совместимость и ограничения

Проверено только с **Windows, русским настольным Телемостом 3.1.3
и масштабом экрана 100%**. Браузерная версия не поддерживается.

Утилита отправляет нажатие по фиксированным координатам кнопки микрофона
внутри окна. Она не получает состояние микрофона через API. Другие версии,
языки, DPI/масштабы и изменения панели звонка не проверены: нажатие может
не сработать или попасть в другой элемент. Перед настоящим разговором
обязательно проверьте переключение в пустом звонке и убедитесь по значку,
что изменился именно микрофон. Не используйте утилиту как гарантию отключения
звука. Очень маленькие окна и несколько окон звонка не поддерживаются.

## Запуск без установки

### Готовый установщик (Python не нужен)

Запустите `TelemostHotkey-Setup-0.1.0.exe` и завершите установку.
Автозапуск включён по умолчанию. Утилита устанавливается в
`%LOCALAPPDATA%\Programs\TelemostHotkey` только для текущего пользователя.
После установки откройте Телемост и проверьте правый Shift в пустом звонке.
Удаление доступно в списке установленных приложений Windows.

Сборка не имеет цифровой подписи издателя.

### Запуск исходников

Нужны Windows и установленный **Python 3.10+** с `pythonw.exe`.
Сторонние библиотеки не требуются.

Скачайте файлы в постоянную папку и в терминале этой папки
выполните:

```powershell
pythonw.exe .\telemost_hotkey.pyw --watch
```

Затем откройте Телемост и пустой звонок. Переключитесь в другое приложение,
нажмите правый Shift и проверьте значок микрофона в Телемосте.
Повторное нажатие должно вернуть прежнее состояние.

## Автозапуск для текущего пользователя

В PowerShell из папки проекта:

```powershell
.\install.ps1
```

Если Python не найден автоматически:

```powershell
.\install.ps1 -PythonPath 'C:\путь\к\Python\python.exe'
```

Скрипт создаёт ярлык `Telemost Right Shift Mic` в пользовательской папке
автозагрузки и запускает наблюдатель сразу. Права администратора не нужны.
Не перемещайте папку после установки. Если политика PowerShell не разрешает
скрипты, используйте ручной запуск выше либо создайте такой ярлык вручную;
установщик не меняет политику безопасности Windows.

## Удаление

Из той же папки выполните:

```powershell
.\uninstall.ps1
```

Скрипт удаляет ярлык, указывающий на эту копию, и останавливает её процессы.
Исходные файлы и журналы остаются. Альтернатива: удалить ярлык из автозагрузки
и завершить соответствующий `pythonw.exe` через Диспетчер задач, проверив
путь `telemost_hotkey.pyw` в командной строке процесса.

## Данные

Сетевых запросов, записи звука и отправки данных нет. Другие клавиши
не сохраняются. Журналы `watcher.log` и `worker.log` в
`%LOCALAPPDATA%\TelemostHotkey` содержат события запуска, переключения и ошибки.
Размер каждого ограничен 256 КБ плюс одна резервная копия.
После ошибки обработчик перезапускается с задержкой 10 секунд.
Журналы и `__pycache__` исключены через `.gitignore`; не добавляйте их вручную
в публикацию. Публичная лицензия пока не выбрана.

## Сборка EXE

Нужны Windows x64, Python и Inno Setup 7 с компилятором ISCC.

```powershell
python -m pip install pyinstaller==6.22.3
python -m PyInstaller --noconfirm --clean --onefile --windowed --name TelemostHotkey --distpath dist --workpath build telemost_hotkey.pyw
& 'C:\путь\к\Inno Setup\ISCC.exe' setup.iss
```

В готовый EXE включается интерпретатор Python. Автоматические тесты исходников:
`python -m unittest discover -p 'test_*.py' -v`.
