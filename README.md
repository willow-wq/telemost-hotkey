# Telemost Hotkey

Неофициальная утилита для переключения микрофона в настольном Яндекс Телемосте
из другого окна. По умолчанию используется правый Shift.

## Windows

[Скачать установщик 0.2.0](https://github.com/willow-wq/telemost-hotkey/releases/download/v0.2.0/TelemostHotkey-Setup-0.2.0.exe)
· [Все релизы](https://github.com/willow-wq/telemost-hotkey/releases)

1. Запустите установщик. Python отдельно устанавливать не нужно,
   права администратора не требуются. Автозапуск включён по умолчанию.
2. Откройте приложение Телемост и войдите в звонок.
3. Нажмите правый Shift: микрофон переключится. Повторное нажатие вернёт его состояние.

Чтобы выбрать другую клавишу: **Пуск → Настроить клавишу Telemost → Сохранить**.
Поддерживается одна клавиша без сочетаний. Изменение применяется в течение секунды.
Во время звонка выбранная клавиша занята микрофоном во всех окнах.

После завершения звонка перехват клавиши отключается. При выходе из Телемоста
обработчик завершается; фоновый наблюдатель остаётся для следующего запуска приложения.
Обнаружение изменений занимает примерно 1–2 секунды.

Удаление: **Параметры Windows → Приложения → Telemost Right Shift Mic**.

### Совместимость

- Windows x64, начиная с Windows 10 1703. Проверено с русским Телемостом 3.1.3.
- Координаты кнопки пересчитываются по DPI окна. Автоматические тесты расчётов
  охватывают 100–400%; реальные звонки при всех масштабах и перенос между мониторами
  с разным DPI ещё не проверены.
- Изменения панели Телемоста и нестандартный масштаб Qt могут нарушить работу.
  Несколько окон звонка и слишком маленькие окна не поддерживаются.
- Установщик не имеет цифровой подписи издателя.

Перед разговором проверьте смену значка микрофона в пустом звонке.
Утилита нажимает кнопку приложения и не получает состояние микрофона через API.

## Ubuntu

[Экспериментальные исходники](https://github.com/willow-wq/telemost-hotkey/releases/download/v0.2.0/TelemostHotkey-Ubuntu-experimental-0.2.0.zip)
· [Инструкция](linux/README.md)

Для X11 предусмотрена глобальная клавиша. Для Wayland — отдельная команда,
которую можно назначить на системное сочетание. Нужна доступная именованная
кнопка микрофона через AT-SPI; если её нет, действие не выполняется.
На настоящем Ubuntu вариант ещё не проверен. Это прототип, а не готовый установщик.

## Данные

Сетевых запросов, записи звука и сохранения нажатий клавиш нет.
Windows-настройки и журналы находятся в `%LOCALAPPDATA%\TelemostHotkey`.
Журналы содержат запуск, переключения и ошибки; их размер ограничен.

## Разработка

Исходники Windows требуют Python 3.10+ и только стандартную библиотеку.
Запуск: `pythonw telemost_hotkey.pyw --watch`.
Настройки: `pythonw telemost_hotkey.pyw --settings`.
Автозапуск исходников: `install.ps1`; отключение: `uninstall.ps1`.

Тесты: `python -m unittest discover -p 'test_*.py' -v`.
Тесты Ubuntu запускаются отдельно из папки `linux`.

Сборка на Windows x64 с Python, PyInstaller и Inno Setup 7:

```powershell
python -m pip install pyinstaller==6.22.3
python -m PyInstaller --noconfirm --clean --onefile --windowed --manifest TelemostHotkey.manifest --name TelemostHotkey --distpath dist --workpath build telemost_hotkey.pyw
& 'C:\путь\к\Inno Setup\ISCC.exe' setup.iss
```
