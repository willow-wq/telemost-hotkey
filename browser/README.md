# Настраиваемая клавиша для веб-версии Телемоста — 0.2.0

Экспериментальное расширение для Chromium/Chrome/Яндекс Браузера и Firefox на Windows или Linux.
Выбранная клавиша (по умолчанию правый Shift) один раз нажимает кнопку включения/выключения микрофона **только в активной,
сфокусированной вкладке Телемоста**. Из другой программы или вкладки оно не работает.
Это ограничение отличается от Windows-программы для настольного Телемоста.

Расширение не зависит от координат и масштаба: ищет единственную доступную видимую кнопку
с явным названием вроде «Выключить микрофон» или «Unmute microphone» в `aria-label`,
`title` или тексте. Если кнопки нет, их несколько или название неизвестно, ничего не делает.
При вводе в текстовое поле, повторе удерживаемой клавиши и сочетаниях клавиш не срабатывает.
Включить микрофон вопреки запрету организатора оно не может.

## Установка из ZIP в Chromium / Chrome / Яндекс Браузер

1. Распакуйте ZIP в постоянную папку. В ней должен находиться `manifest.json`.
2. Откройте страницу расширений браузера (например, `chrome://extensions`).
3. Включите режим разработчика и выберите «Загрузить распакованное расширение».
4. Выберите папку с `manifest.json`. Перезагрузите вкладку Телемоста.

В разных сборках Яндекс Браузера доступность установки распакованных расширений может отличаться.

## Временная установка в Firefox

1. Распакуйте ZIP и откройте `about:debugging#/runtime/this-firefox`.
2. Выберите «Загрузить временное дополнение» и файл `manifest.json`.
3. Перезагрузите вкладку Телемоста.

Это неподписанное дополнение: временная установка исчезает после перезапуска Firefox.
Для постоянного распространения нужна отдельная подпись через Mozilla.

## Выбор клавиши

Откройте настройки расширения на странице управления расширениями браузера.
Нажмите «Выбрать клавишу» и нажмите одну клавишу, например F8. Escape отменяет выбор.
«Вернуть правый Shift» восстанавливает исходное значение. Выбирается физический код клавиши
(`KeyboardEvent.code`), поэтому смена раскладки не меняет привязку.
Значение сохраняется локально в браузере через разрешение `storage` и сразу применяется
к открытым вкладкам. При обновлении с 0.1.0 перезагрузите вкладку Телемоста один раз.
Системные клавиши и сочетания, которые браузер не передаёт странице, расширение не перехватывает.
Привязка букв действует вне полей ввода и заменяет обычное действие буквы на странице звонка.

## Проверки и ограничения

Запуск тестов без зависимостей: `node --test test.js`.
Тесты проверяют распознавание названий, решения о клавишах и сохранение настройки
на искусственных данных и имитации API браузеров.
Реальный звонок в браузере не проверен. Публичная стартовая страница Телемоста требует JavaScript
и не предоставляет статического описания кнопки; проверяемого селектора из документации нет.
Новые названия кнопок, вложенные фреймы или Shadow DOM могут потребовать обновления расширения.
Перед важным звонком проверьте смену значка микрофона вручную в пустом звонке.

Сайты: `telemost.yandex.ru`, `telemost.360.yandex.ru` и их `.com` варианты, только HTTPS.
Нет сетевых запросов, аналитики, удалённых скриптов, background/service worker,
доступа к другим вкладкам, звуку, микрофону или содержимому вне перечисленных сайтов.
При закрытии вкладки обработчик исчезает вместе с ней.
