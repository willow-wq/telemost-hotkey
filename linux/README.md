# Ubuntu: экспериментальный вариант для X11

**На Ubuntu не тестировался.** Это прототип для отдельной проверки,
не обещание поддержки всех версий Телемоста, Chrome или Firefox.

Автоматический глобальный правый Shift поддерживается только в X11.
Проверьте `echo "$XDG_SESSION_TYPE"`: для него требуется `x11`.
Для Wayland есть отдельный однократный режим ниже; глобального перехвата
клавиатуры в Wayland этот проект не реализует.

## Зависимости и запуск

```sh
sudo apt install python3 python3-xlib python3-pyatspi
cd linux
/usr/bin/python3 telemost_hotkey.py
```

Требуется работающая инфраструктура AT-SPI и доступное дерево приложения.
В браузере доступность страницы может зависеть от версии, настроек и упаковки
(в том числе Snap/Flatpak). Chrome и Firefox не гарантируются. Скрипт сам
не меняет настройки доступности. Если дерево не содержит кнопку, клавиша
не назначается. Для Chrome иногда требуется запуск с параметром
`--force-renderer-accessibility`; это не гарантирует работоспособность.

## Выбор клавиши в X11

По умолчанию используется правый Shift (`Shift_R`). Можно выбрать другую
одиночную клавишу по её X11 keysym, например F8:

```sh
/usr/bin/python3 telemost_hotkey.py --key F8
```

Для сохранения выбора создайте файл
`~/.config/telemost-hotkey/config.json` (или
`$XDG_CONFIG_HOME/telemost-hotkey/config.json`, если переменная задана):

```json
{"hotkey": "F8"}
```

Автозапуск читает этот же файл; менять установочный ярлык не нужно.
После изменения перезапустите утилиту (Ctrl+C в терминале; для фоновой копии
выйдите из сеанса и войдите снова). `--key` имеет приоритет над файлом.
Поддерживается одна клавиша, а не комбинации вроде `Ctrl+M`. Ограничения
удержания/автоповтора и передачи клавиши активному приложению применяются
также к выбранной клавише. Для Wayland клавишу выбирают в настройках
рабочего стола для команды `--toggle-once`, а не через `--key`.

## Поведение

Скрипт ищет через AT-SPI одну доступную кнопку с точным именем действия
«Включить микрофон», «Выключить микрофон», «Отключить микрофон»,
`Mute microphone`, `Unmute microphone`, `Turn microphone on/off`.
Для настольного приложения распознаются имена Telemost/Яндекс Телемост;
для браузера требуется HTTPS-адрес документа с точным доменом
`telemost.yandex.ru` или `telemost.360.yandex.ru`.

Если подходящая кнопка одна, правый Shift вызывает её действие даже из другого
окна. При отсутствии или неоднозначности кнопки нажатия не выполняются.
Если Qt-версия приложения предоставляет кнопку без доступного имени,
скрипт её не распознает и ничего не нажмёт: угадывания по порядку кнопок нет.
Нет кликов по координатам и отключения системного микрофона. Предпросмотр
входа также может содержать такую кнопку: в этом случае переключается
микрофон предпросмотра. Обнаружение изменений занимает примерно секунду.

X11 повторно передаёт Shift активному приложению, поэтому он остаётся
модификатором, но одновременно переключает микрофон. Во время звонка для
набора текста используйте левый Shift. При смене раскладки/карты клавиш
может потребоваться перезапуск. Если клавиша уже занята, скрипт не отбирает её.
Используйте короткие одиночные нажатия. Удержание правого Shift и его
автоповтор не поддерживаются и могут повторно переключать микрофон.

Сначала проверьте на пустом звонке, что правый Shift меняет именно значок
микрофона. По завершении закройте звонок и проверьте обычное поведение Shift.
Не полагайтесь на прототип как на гарантию выключенного звука.

## Автозапуск и удаление

```sh
sh install.sh
sh uninstall.sh
```

Установка без `sudo`, в автозапуск текущего пользователя; исходную папку
после этого перемещать нельзя. Сам скрипт установки процесс не запускает.
Наблюдатель работает после входа в систему, назначение клавиши появляется
только при найденной кнопке. Удаление отключает следующий автозапуск;
для завершения текущего процесса нажмите Ctrl+C в терминале или выйдите
из сеанса. Сеть, запись звука и запись нажатий не используются.

## Wayland или собственная системная горячая клавиша

Однократный режим использует только AT-SPI и не перехватывает клавиши:

```sh
/usr/bin/python3 /полный/путь/linux/telemost_hotkey.py --toggle-once
```

Его можно назначить на пользовательское сочетание в настройках клавиатуры
GNOME или другого рабочего стола, если приложение/браузер предоставляет
доступную кнопку через AT-SPI. Выберите сочетание, которое поддерживает
ваш рабочий стол, например Ctrl+Alt+M. Назначение одного правого Shift
в системных настройках не гарантируется. Команда вне доступного звонка
ничего не нажимает и завершается с сообщением об отсутствии подходящей кнопки.
Автозапуск для этого режима не нужен. Wayland и этот режим на Ubuntu
не тестировались; поддержки GlobalShortcuts portal в проекте нет.

Проверка чистых функций сопоставления (не проверяет X11/AT-SPI):

```sh
/usr/bin/python3 -m unittest test_matching.py
```
